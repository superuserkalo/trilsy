# How to run this

These files live in `docs/redesign-brief/`. The standing design rules are in the root `CLAUDE.md`, which every session loads on its own. Start a **fresh Claude Code session per phase**. Paste:

> Read `docs/redesign-brief/00-master.md`, then do only `docs/redesign-brief/01a-phase-a-references-copy.md`. Follow the co-design rules. Stop at the gate.

Then the same for `01b`, `02`, `03`, `04`, `05`. Phase D runs as one session per section: its first session writes the tickets, and each later session builds one. Each session reads `/docs/redesign/STATE.md`, which the previous phase wrote, so nothing is lost between sessions.

Before Phase A: nothing required. During Phase B you will get a few one-click questions (hero, logo, integrations, copy). Phase C can be skipped in practice if you are happy with no shader.
