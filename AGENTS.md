# Trilsy project guidance

- Keep the repo lean. Mac notetaking and the marketing site are the current scope.
- Before every UI design phase, inspect relevant Mobbin images. Use the actual visual references, not search metadata. Record the source links and what informed the design.
- Superwhisper is the primary marketing reference: immersive artwork, clear typography, focused product presentation. Keep Trilsy's identity original.
- The existing daylight design is not approved by the owner; a redesign is expected. Do not treat the current palette or composition as fixed. Do not add a pill or badge above the hero headline. Use an honest product-fact trust strip, never invented logos or certifications.
- Use Tailwind utilities for layout and shadcn/ui for controls. Keep global CSS to tokens, base rules, and motion definitions.
- Use the installed shadcn and vgpu skills. Read vgpu docs from the installed package version.
- Verify the rendered page and interactions on desktop and narrow layouts before deployment. Check the WebGPU fallback and reduced-motion behavior.
- Keep release claims honest. There is no signed Mac installer or public release yet. Do not add fake testimonials, customer counts, or unavailable downloads.
